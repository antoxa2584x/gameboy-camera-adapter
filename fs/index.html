What the LED colors mean
  • Your color — ready
  • Blue blink — receiving a photo
  • Cyan blink — live view
  • Orange blink — printing
  • Purple — updating firmware
  • Red blink — print or update failed

Manual update (USB drive)

1. Download the .uf2 file from the GitHub releases.

2. Click "Force Update Mode". The Adapter will appear as a new USB drive named "RPI-RP2".

3. Drag and drop the .uf2 file into the RPI-RP2 drive. The Adapter reboots on its own.

Needs a Mac or Windows PC. Also the way back if an update was ever interrupted: the Adapter then shows up as RPI-RP2 by itself.
