Update Instructions

1. Download the latest firmware from the button below:

.uf2 file from assets

2. Click the "Force Update Mode" button. The Adapter will appear as a new USB drive named "RPI-RP2".

3. Drag and drop the downloaded .uf2 file into the RPI-RP2 drive.

4. The Adapter will reboot automatically and be ready to use!

Note: If you are on iPhone/iPad, you need a Mac or Windows PC to perform the update.
